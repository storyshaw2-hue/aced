# ACED project reference

ACED is a universal study-pack game, not a subject-specific course or content storefront. The current architecture, pages, data contract, tests and limitations are documented in [README.md](README.md).

## Product principles

- **One engine:** every subject uses the same poker hands, jokers, shops and boss rounds.
- **Packs are content:** authors supply questions, answers, choices, explanations and topics, not game mechanics or code.
- **The library is personal:** save multiple independently identified packs and switch material without mixing progress.
- **Learning is separate:** gameplay earns XP; answering questions affects recall progress. Self-rated recall is labeled.
- **Honest input:** structured material is parsed deterministically. No claim that arbitrary paragraphs become reliable questions.
- **Local-first privacy:** no account is necessary; storage limitations and sharing implications are visible.
