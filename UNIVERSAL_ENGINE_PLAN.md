# Universal study-pack engine

The shipped foundation is one neutral game with a persistent personal collection. The implementation contract and validation commands live in [README.md](README.md).

## Implemented foundation

- Upload and paste structured material, review and edit, then save and play.
- Multiple stable pack IDs, independent progress, edits, exports and direct sharing.
- Shared poker rules and joker effects; no subject-specific game vocabulary or paid-content gates.
- Question-based recall progress, distinct game XP, spaced review and graded-answer confidence.
- Seeded daily play, recoverable loading errors and storage-unavailable warnings.

## Deliberately not claimed

- A hosted public/community pack catalog or moderation system.
- Accounts or cross-device syncing of the new pack collection.
- AI question generation, document understanding, or PDF parsing.
- A scientifically validated forecast of outside-game performance.

## Sensible next boundaries

- Evaluate the repeatable import-to-play loop with real users before adding game modes.
- If public pack publishing is introduced, add author permissions, versioning, moderation and clear content rights.
- If cloud sync is introduced, specify conflict handling and export/backup behavior before connecting the personal library.
- If AI generation is introduced, require answer provenance, review and cost/privacy controls rather than disguising it as deterministic parsing.
