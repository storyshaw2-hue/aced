# Capability truth matrix

Baseline: `main` @ `0252f6dc`. The classifications are based on code only. Marketing copy, README text, comments and UI labels were **not** accepted as evidence that a capability works. Citation conventions are in `production-topology.md`.

Legend: **verified** means implemented in code reachable from a public route. **partial** means implemented with material gaps or only on a legacy route. **planned** means scaffold or copy only. **misleading** means public copy claims more than the code does. **not found** means no implementation was located.

"Verified" here means statically verified. No browser execution was performed in this audit (see `test-baseline.md`).
