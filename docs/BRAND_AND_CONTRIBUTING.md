# Brand and contributing

ACED is a game for whatever someone is learning. Speak to players bringing their own material, not to one profession or one credential.

## Vocabulary

- **Study pack:** questions, answers, explanations and topics.
- **Round / stage / challenge:** neutral game progression.
- **Game XP / player level:** rewards for playing.
- **Recall progress:** evidence from answers, separate from game scoring.
- **My packs / starter packs:** a personal collection and a few examples, not a claimed public marketplace.

## Visual direction

Keep the recognizable dark green terminal, restrained pixel display type, legible monospace body text, poker cards and gold joker panels. Use `app.css` across the main flows. Mobile must have readable questions and usable card controls, not a scaled-down desktop layout.

## Contributor checklist

Follow [.github/copilot-instructions.md](../.github/copilot-instructions.md), run the test suite, check the upload-to-play loop in a browser and inspect desktop and narrow layouts. Escape every user-derived string and test storage and import failures, not just the happy path.
